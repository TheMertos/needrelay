# Discovery open-details + landing width

**Date:** 2026-09-18  
**Status:** Approved  

## Goal

Add a visible “Open details” control on each discovery help-point card linking to `/r/{publicSlug}`, and constrain the landing page width to match the public relief page (`Container size="lg"`).

## Locked decisions

| Topic | Choice |
| --- | --- |
| Placement | Each help-point card on Discovery |
| Navigation | Link to `/r/{publicSlug}` |
| Width | `Container size="lg"` like `PublicReliefPage` |
| Drawer | Unchanged |

## Non-goals

- New API / new detail route per need
- Removing the need drawer
